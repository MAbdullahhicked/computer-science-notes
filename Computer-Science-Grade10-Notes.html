1.1 Machine-level representation of data

Inside the machine there is no "5", no "A", no photo. There are only bits — switches that are either 0 or 1. A bit is the smallest unit of information; eight of them make a byte. Everything else is a convention for reading a pattern of bits: the same 8 bits can be a number, a character or one channel of a colour.

How the same bit pattern gets read depends on its data type:

TypeWhat it storesHow it is held
Integerwhole numbersfixed number of bits; leftmost bit is the sign
Floating pointreal numbers with fractionsIEEE 754: sign + exponent + mantissa
Characterletters, digits, symbolsa code number (ASCII / Unicode)
Booleantrue or falseone bit: 1 or 0

An 8-bit signed integer runs from −128 to +127; unsigned, the same 8 bits run from 0 to 255. That is not a detail — it is the reason calculators wrap around to a wrong answer.

ANALOGY

A bit is a light switch. One switch tells you almost nothing; eight switches in a row can spell out 256 different on/off combinations — like a row of eight switches in a shop window, where every pattern means a different product.

1.2 Number systems

A number system is just a set of symbols plus a rule for what each position is worth. It is positional: in 964, the 9 means nine hundreds only because of where it sits.

SystemBaseDigits allowedWhere you meet it
Decimal100–9everyday counting
Binary20, 1the hardware itself
Octal80–7short-hand for binary (3 bits per digit)
Hexadecimal160–9, A–Fcolour codes, memory addresses, short-hand (4 bits per digit)

Each position is worth baseposition, counting from 0 at the right. So 1011.101₂ = 8 + 0 + 2 + 1 + ½ + 0 + ⅛ = 11.625. That single line is the whole "any base → decimal" method.

Converting: pick the direction

  • Any base → decimal: multiply each digit by its place value and add.
  • Decimal → any base: divide by the base and collect remainders, bottom to top.
  • Octal ↔ binary: swap each octal digit for 3 bits. Hex ↔ binary: 4 bits.
  • Octal ↔ hex: go through binary or decimal — no direct shortcut.
WORKED EXAMPLE · the only one you need

(1BE8)₁₆ → decimal
1×16³ + 11×16² + 14×16¹ + 8×16⁰ = 4096 + 2816 + 224 + 8 = 7144.
Check the reverse: 179 ÷ 2 leaves remainders 1 1 0 0 1 1 0 1, read upwards → 10110011.

1.2.3 Binary arithmetic, overflow and complements

Addition works exactly as in decimal, with four facts: 0+0=0, 0+1=1, 1+0=1, and 1+1=10 (write 0, carry 1). Subtraction borrows in the same way.

Overflow is when the answer needs more bits than the register has: 255 + 1 in 8 bits gives 100000000₂, and the ninth bit is lost, so the register shows 0. Underflow is the mirror problem for values too small to represent. The fixes are bigger data types, range checks, or library support.

Computers avoid a separate subtraction circuit by using complements. The 1's complement flips every bit; the 2's complement flips then adds 1. So −13 in 8 bits is 00001101 → flip → 11110010 → +1 → 11110011. The sign bit (leftmost) being 1 is what marks a negative number.

EXAM TIP

Marks are lost for skipping the sign bit. Write "8-bit two's complement" and show the flip-then-add-one step in two lines — examiners award the method even if the final bit is wrong.

1.3 Coding schemes: ASCII and Unicode

A coding scheme is an agreed dictionary between characters and numbers, so that two different machines read the same bytes the same way.

  • ASCII (1963) used 7 bits → 2⁷ = 128 characters. Extended ASCII used 8 bits → 256. Enough for English, not for the world.
  • Unicode (1991) gives every character in every script a unique number — over 100,000 today, including emoji. Its storage formats are UTF-8, UTF-16 and UTF-32.
ANALOGY

ASCII is a 128-seat cinema — fine for one neighbourhood. Unicode is a global stadium where every language gets a seat, and UTF-8 is the ticket system that squeezes common Latin letters into one byte but lets rare characters take more room.

'A' = 65  ·  'a' = 97  ·  '0' = 48  ·  'A' in 8-bit binary = 01000001

1.4 The operating system

The operating system is the software loaded into RAM at start-up that stands between you and the hardware. Windows, macOS, Linux, Android and iOS are the familiar ones. It performs six jobs: process, memory, file, device, network and security management.

Processes and threads

A program is a file sitting on disk. Once it is loaded into RAM and running, it is a process — the basic unit of work, with five states: new → ready → running → waiting/blocked → terminated. A thread is a sequence of instructions inside a process. Threads share memory; processes do not.

The scheduler decides whose turn the CPU is. An interrupt is a signal that jumps the queue (an incoming email, a key press). A deadlock is when two processes each hold what the other needs and both wait forever.

ANALOGY

Processes are separate flats with their own keys. Threads are flatmates sharing one kitchen — faster to work together, but one leaving a mess affects everybody. A deadlock is two people each holding the other's door key.

Types of OS — learn the one-line difference

TypeWhat makes it differentSeen in

File systems organise storage into files, folders and metadata. Single-level is one flat folder; two-level gives each user a folder; tree is the normal hierarchy. Files are allocated contiguously (fast, fragments), linked (flexible, slower) or indexed (a pointer table). FAT is old and simple, NTFS adds security and large files, ext4 is the Linux workhorse with journaling.

1.5 Computer software

KindJobExamples
System softwareruns the machine and hosts everything elseWindows, macOS, Linux, Android
Application softwaredoes a task for the userWord, Chrome, Spotify
Programming softwarewrite, test and translate codeVS Code, Eclipse, GCC

An offline application runs from local resources (Word, Photoshop, VLC); an online application needs a server (Google Docs, Gmail, Spotify streaming). A patch is a small update that fixes bugs, closes a security hole, improves speed or adds a feature.

Where software lives

The programmer's tools

Programming software is the workshop: a text editor writes code (Notepad++, Sublime Text, VS Code); an IDE bundles the editor, debugger and compiler in one window (Eclipse, IntelliJ, Visual Studio); a compiler translates the high-level code into machine code (GCC for C/C++, javac for Java). Modern editors add syntax highlighting, code completion and real-time error checking, which is why they catch typos before the program ever runs.

On-premises hosting means your own server room: full control, high cost. Shared hosting puts many sites on one server: cheap but noisy neighbours. Dedicated hosting gives you the whole machine: fast and secure, expensive. Cloud hosting rents scalable capacity by the minute — as much or as little as you need.

EXAM TIP

For hosting questions, the mark scheme usually wants two pros and two cons. Pair them: control vs cost, scalability vs dependence on the internet.

QUICK CHECK

Why is hexadecimal used when the computer only understands binary?

Because one hex digit maps exactly onto four bits, so a long binary string becomes short and human-readable without any conversion maths. 1111 1010 0011 is simply FA3.

State the difference between multiprogramming and multitasking.

Multiprogramming keeps several programs in memory and switches when one is waiting for I/O, to keep the CPU busy. Multitasking switches rapidly between tasks so the user appears to run them all at once.

What happens when an 8-bit unsigned register holding 255 is incremented?

Overflow. The true result is 256 (100000000₂) but only 8 bits fit, so the carry is lost and the register reads 00000000.

UNIT 1 IN ONE BREATH

Bits are the only real data; every base is a different way of reading the same bits, and place value does all the work. The OS turns that hardware into a usable machine by managing processes, memory, files, devices, networks and security — and software is simply everything that runs on top of it.

2.1 Computing problems

A computing problem is one you solve in steps using computation: it takes a well-defined input and must produce an output with certain properties. Three families cover most textbook questions:

FamilyThe answer is…Example
Decisionyes or no“Is 97 prime?”
Searcha set of values meeting a condition“Find a route from Islamabad to Lahore.”
Countinghow many solutions exist“How many routes are there?”

2.2–2.3 Counting principles

Counting problems are easiest to see as a tree: every option becomes a branch, and each complete path from root to leaf is one possible outcome.

PrincipleUse it when…Formula / example
Additionyou choose one of several mutually exclusive options3 desktops + 4 laptops = 7 computers
Multiplicationyou choose one option from each of several stages3 apples × 3 bananas × 3 cherries = 27 baskets
Permutationorder matters4 paintings, 3 wall spaces: 4×3×2 = 24
Combinationorder does not matter24 ÷ 3! = 4 groups
Pigeonholemore items than containers13 apples, 12 baskets → one basket holds 2
Inclusion–exclusionthe two sets overlap|A∪B| = |A| + |B| − |A∩B|
KEY IDEA

Ask one question first: does the order matter? If yes → permutation; if no → combination. Then check whether the sets overlap before you add.

WORKED EXAMPLE

Eight-bit strings that end in 00 or start with 1:
end in 00 → 2⁶ = 64  ·  start with 1 → 2⁷ = 128  ·  both → 2⁵ = 32
64 + 128 − 32 = 160. Subtracting the overlap is the whole trick.

2.4 Algorithms and their properties

An algorithm is a well-defined, finite sequence of rules for solving a problem. It can be written as pseudocode, a flowchart, a program or plain language.

PropertyMeaning in one line
Inputzero or more values supplied from outside
Outputat least one result
Definitenessevery step is clear and unambiguous
Finitenessit ends after a finite number of steps
Effectivenesseach step is simple enough to do with paper and pencil
Generalityit solves a whole class of problems, not one case

Logical reasoning is the engine behind this. Boolean logic reduces any statement to true (1) or false (0), and combines them with AND, OR and NOT — the same operators that later become &&, || and ! in code.

2.6 Standard algorithms

Sorting puts data in order; searching finds one item. Learn the trade-off, not the code: bubble sort is easy but slow, binary search is fast but needs sorted data.

AlgorithmIdeaWatch out for
Bubble sortswap neighbouring items until none are out of ordermany passes on large lists
Selection sortrepeatedly pick the smallest and move it to the sorted endalways scans the whole rest
Insertion sortslot each new item into its place, like sorting cards in your handslow on reversed data
Merge sortsplit in half, sort each half, mergeneeds extra memory
Linear searchcheck items one by oneworks on unsorted data, but slow
Binary searchhalve the sorted range each timeuseless if the list is not sorted

2.7 The four pillars of computational thinking

PillarWhat you doExample
Decompositionbreak the big problem into smaller onesa school app → login, timetable, results
Pattern recognitionspot what repeatsevery report needs a title, table, total
Abstractionkeep what matters, drop the resta metro map keeps stations, ignores streets
Algorithm designwrite the stepsthe recipe for adding a student
ANALOGY

Making tea is a perfect 7-step algorithm: boil water, add the bag, pour, wait, remove, add sugar and milk (optional), stir. Anyone can follow it and get the same cup — that is what “definite” and “general” mean.

2.9–2.11 Generalise, modularise, dry-run

A specific solution solves today's case; a general solution solves the family of cases. Swap constants for variables, extract the common pattern, and test with different inputs. Modular design then splits the system into interchangeable modules with defined interfaces: define, design interfaces, implement, integrate, test — both each module and the whole.

A dry run executes the algorithm by hand on chosen inputs, recording every variable in a trace table. It finds logic errors before a computer ever runs the code.

Dry run of “find the largest number” on [3, 1, 4, 1, 5, 9, 2, 6]

end—99answer = 9

Two kinds of error

A syntax error breaks the grammar — the program will not run at all (missing bracket, misspelled keyword). A logical error runs fine and gives the wrong answer, because the reasoning is wrong. A search query of “smartphones under 500” may return used phones (logic) and wrong-currency results (syntax).

EXAM TIP

Trace-table questions give marks per row, not just the final answer. Draw the table with one column per variable and one row per step, even when the question seems short.

QUICK CHECK

A class of 50: 30 did maths, 25 did science, 15 did both. How many did at least one?

30 + 25 − 15 = 40. The 15 are counted twice if you simply add, so include–exclude.

Why can binary search not be used on an unsorted list?

It decides which half to discard by comparing with the middle value. Without order, the target could be in either half, so the decision is meaningless.

Which algorithm property stops an infinite loop from being called an algorithm?

Finiteness — an algorithm must terminate after a finite number of steps.

UNIT 2 IN ONE BREATH

Decompose the problem, spot the pattern, strip it to the essential (abstraction), then write finite, definite steps. Counting asks whether order matters; algorithms are judged by six properties; and a dry run on paper is cheaper than a bug in code.

3.1 How a website is built

Website development runs in a loop: plan the purpose, design the navigation, build, test, launch. The build splits into two halves, and the split is deliberate — each half can change without breaking the other, and each needs a different skill set.

Front-end (client-side)Back-end (server-side)

LanguagesHTML, CSS, JavaScriptPython, PHP, Ruby, SQL
Goalattractive, usable, responsivecorrect, secure, fast answers

Responsive design lets one site fit every screen: widths in percentages rather than fixed pixels, and layouts that stack. A desktop menu becoming a stacked mobile menu is the classic example.

3.2 Forms in HTML

A form is a paper form on screen. The <form> tag wraps it, each <input> collects one field, and <label> tells the user what to type. The type attribute decides which control appears.

3.2.3 Animation in CSS

An animation is a set of keyframes — snapshots of an element's style at 0% and 100% — plus a rule that says how long to take and how often to repeat. The browser interpolates everything in between. 

@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

#box {
  width: 100px; height: 100px; background: #b23b2e;
  animation: spin 2s infinite linear;   /* name | duration | repeat | easing */
}
ANALOGY

@keyframes is a flip-book: you draw only the first and last page, and the browser draws all the pages in between at 60 per second.

3.3 JavaScript: making the page react

HTML and CSS produce a static page — the same thing on every visit. JavaScript makes it dynamic: it responds to clicks, validates input, updates part of the page without a reload, and builds menus and slideshows.

Arrays: one box with numbered slots

An array stores many values in one variable. Indexing starts at 0, which is the single most common source of off-by-one marks.

MethodDoes
push(x)adds x at the end
indexOf(x)returns the index of x, or −1
toString()joins all elements into one comma-separated string

// a loop visits every element; the DOM shows the result
const fruits = ["apple", "banana", "orange"];
let text = "";

for (let i = 0; i < fruits.length; i++) {
  text += fruits[i] + (i < fruits.length - 1 ? ", " : "");
}
document.getElementById("out").textContent = text;

document.getElementById() finds an element; .textContent replaces its text. That pair is enough for most question-3 answers. A function wraps repeated work under one name, so one definition can be called many times.

3.4 Arrays vs lists

A list is an ordered sequence — an Abstract Data Type, meaning we define the operations ourselves. An array is JavaScript's built-in version of that idea. Both hold any type, both grow and shrink, both are indexed from 0.

ArrayList
stored in contiguous memorymemory locations need not be contiguous
built into JavaScript with [ ]not built in; built from arrays or nodes
resizing may need rearrangementresizes more easily
methods already providedyou define the operations
best for numbers and simple tasksbest when you need flexibility

To find an item you walk the list until it matches — the same linear search from Unit 2. If it is found, return early; if the loop finishes without a match, report “not found”.

3.5 Testing and debugging

A unit test checks one small piece of code in isolation with a known input and an expected output. Two tests for a search function: search for an item that exists → expect true; search for one that does not → expect false. Tests catch errors early and let you refactor with confidence.

Debugging is observation, not guessing. A breakpoint pauses execution on a chosen line so you can inspect variables. A watchpoint pauses when an expression changes. Step over line by line and the bug reveals itself. 

// logical error: one trip too many, so the last read is undefined
for (let i = 0; i <= fruits.length; i++) { ... }   // indices 0,1,2,3 — but 3 does not exist

// fix: use the strict less-than
for (let i = 0; i < fruits.length; i++) { ... }
EXAM TIP

When asked to “find the error”, say what is wrong, where it is, and what to write instead. An unclosed tag is a syntax error; a loop with the wrong start value is a logical error.

QUICK CHECK

Why does myArray[3] fail on a three-element array?

Indexing starts at 0, so a three-element array has valid indices 0, 1 and 2. Index 3 is one past the end and returns undefined.

What is the difference between front-end and back-end?

The front-end is everything rendered and interacted with in the browser (HTML, CSS, JavaScript). The back-end is the server-side logic and database that processes requests and returns data.

Which input type would you use for “choose one delivery method”?

Radio buttons, because they allow exactly one choice from a group that shares the same name.

UNIT 3 IN ONE BREATH

HTML gives structure (forms, tables, lists), CSS gives appearance and motion, and JavaScript gives behaviour. Arrays hold collections, loops walk them, functions name the work, and tests plus breakpoints prove the whole thing actually does what you claim.

4.1 Data science, AI and machine learning

Data science is the interdisciplinary field that combines mathematics, statistics and computer science to extract insight from data — structured or unstructured. The work runs through collection, cleaning, preprocessing and visualisation.

Artificial intelligence is the ability of a machine to behave intelligently: to reason, understand language and interact with its environment. The idea is old — Alan Turing proposed his test in 1950 — but the current wave runs on data.

Machine learning is the subset of AI where the system learns patterns from data instead of being given explicit rules. It is the engine inside most of what people call “AI”.

ANALOGY

Data science is a detective studying years of case files to find a pattern. Machine learning is a trainee who learns the pattern by studying solved cases. AI is the whole police department behaving intelligently — and the trainee works inside it.

AspectData scienceArtificial intelligenceMachine learning
Goalinsight and informed decisionsmachines that behave intelligentlylearn patterns from data
Toolsstatistics, data mining, visualisationneural networks, expert systems, NLPsupervised, unsupervised, reinforcement, deep learning

The three learning models

ModelData givenHow it learnsExample
Supervisedlabelled — questions with answersmaps input to the known output, then predicts for new inputfruit classifier trained on shape, colour, texture → name
Unsupervisedunlabelledgroups data by similarity and differencenews articles automatically sorted into politics, sport, health
Reinforcementno dataset — feedbackagent acts, gets reward or penalty, improvesa chess player learning which opening wins
KEY IDEA

Ask: are the answers in the data? Labels present → supervised. No labels, find groups → unsupervised. An agent chasing a goal → reinforcement.

Training follows four steps: split the clean data into training, testing and validation sets; pick an algorithm (neural network, decision tree); train it to learn the pattern; then test it against data it has never seen and compare with the real values.

Two business applications worth naming: churn prediction estimates which customers are about to leave, so offers can be sent before they do; behavioural segmentation groups customers by purchase frequency, brand loyalty and response to offers. Keeping an existing customer is usually cheaper than winning a new one.

4.3 The data science life cycle

Seven stages, and the process is a loop — evaluation often sends you back to modelling.

StageWhat happensOutput

A KPI is a measurable target: “raise sales 15% in two months”, “make the site load 20% faster in 30 days”. Without a KPI you cannot tell whether the model worked.

CASE STUDY · smartphone inventory

A superstore wants popular phones in stock without over-buying. KPIs: never run out of top sellers; cut dead stock. Data: sales history, stock levels, seasonality. Analysis: which models sell fastest and which sit too long. Model: predicts demand and raises a reorder alert. Evaluation: accuracy, timely alerts, cost saving. Deploy: alerts in the existing sales software. Monitor: tune reorder levels as tastes change.

QUICK CHECK

A shop wants to group customers by buying habits, with no predefined groups. Which model?

Unsupervised learning — no labels exist, so the algorithm finds groupings (clusters) by similarity.

Why is data cleaning not optional?

Because the model learns whatever is in the data. Duplicates, wrong values and missing fields produce an inaccurate model, and no amount of tuning fixes bad input.

Which chart would show the market share of five phone brands?

A pie chart — the categories are parts of one whole (100% of the market). A bar chart would work for comparing them, but pie is the textbook answer for proportions.

Data science extracts insight, ML learns patterns, AI behaves intelligently. Labels decide the learning model; the question decides the chart; and the life cycle turns a vague business worry into a measured, deployed, monitored system.

5.1–5.2 Internet of Things

The Internet of Things is a network of everyday devices that sense the world, send what they find to the cloud, and act on the result — machine talking to machine with little human involvement.

Sensors are the senses: temperature, humidity, pressure, light, proximity — a phone already carries several. Connectivity is the road to the cloud (Wi-Fi, cellular, Bluetooth, WAN). Data processing is the thinking: analytics platforms and machine learning. User interface is the app or web page that shows you what is happening.

Cryptocurrency is digital money recorded on a blockchain, working through a global peer-to-peer network with no central clearing authority. Bitcoin is the best-known example.

5.6 Cloud computing

Cloud computing delivers servers, storage, databases, networking and software over the internet, paid for as you use it. Instead of buying a server that sits idle, you rent capacity that grows with demand.

BenefitWhat it means in practice
Cost reductionno hardware purchase, no maintenance team
Securityprovider keeps systems patched and restores from backups
Quick accessreach services from any device, anywhere
Scalabilityscale up or down with demand, without new hardware
Collaborationteams work on the same files from anywhere
Automationbackups and updates run without staff

Common uses: file storage (Drive, OneDrive), backup, education (Google Classroom, Coursera), e-commerce, social networks, communication (Teams, Zoom) and cloud gaming.

ANALOGY

On-premises hosting is owning a generator. Cloud is the electricity grid: you pay for the units you use, someone else maintains the plant, and you can draw more power in summer without buying a bigger generator.

5.7 Speech and voice recognition

They sound alike but answer different questions. Speech recognition turns what you said into text — dictation, call centres, medical notes, subtitles. Voice recognition identifies who said it by the unique characteristics of the voice — a biometric password, criminal investigation, national security.

Applications also include AI assistants (Siri, Alexa, Cortana), Quran memorisation apps with recitation and mistake detection, and live language translation.

5.8 Natural Language Processing

NLP is the branch of AI that lets a computer understand written and spoken language the way a human does — meaning, not just keywords.

ApplicationWhat the NLP does
Email filteringspots spam by the words and phrases it contains
Translationconverts speech or text between languages using ML and deep learning
Document analysisextracts and categorises information from piles of files
Predictive textsuggests the next words as you type or search

EXAM TIP

If the question says “understand text or speech like a human”, the answer is NLP. If it says “convert speech to text”, it is speech recognition. If it says “identify a person by voice”, it is voice recognition. Matching the wording earns the mark.

5.9 Robotics

Robotics combines AI with engineering to build machines that perform tasks humans would otherwise do — often in places humans should not be.

  • Rescue: firefighting, earthquakes, floods, rubble removal, supply delivery.
  • Manufacturing: assembly, welding, painting, packaging — repetitive and dangerous work.
  • Domestic: Roomba-style vacuum cleaners that map a room, avoid obstacles and dock themselves.
  • Farming: harvesting, spraying, grafting, palletising, drone surveillance.
  • Space: sample collection, repairs, unmanned missions — no food, water or oxygen needed.
  • Healthcare: surgical assistance, sanitising rooms, delivering medicine and supplies.

5.10–5.11 Bias, ethics and responsibility

AI learns from human data, so it inherits human unfairness. Bias is discrimination by race, ethnicity, gender or age; unethical use is morally wrong use, such as violating privacy or gaining unauthorised access.

In 2015 Amazon found its hiring algorithm favoured men, because it had been trained on ten years of résumés that were mostly male. Facial recognition has similarly produced worse results for people with darker skin tones — a mistake that can ruin someone in a criminal investigation.

Unethical useWhat it looks like
Privacy breachcollecting or exposing personal data without consent
Social manipulationspreading propaganda, manipulating trends and opinions
Cyber security threatusing AI to break into systems, steal identity or money
Market manipulationrigging stock prices and destabilising markets
Deepfakesrealistic fake video of someone saying what they never said

Designers therefore owe users fairness, transparency and impartiality; privacy protection; avoidance of harm; and a genuine benefit to humanity. These are the five duties to quote in a long answer.

QUICK CHECK

Why can a blockchain record not simply be edited later?

Each block stores the hash of the previous block. Altering one block changes its hash, so every later block fails to match and the tampering becomes visible across the shared copies.

Name the five components of an IoT system.

Sensors/devices, connectivity, cloud storage, data processing, and the user interface.

Why is cloud computing described as “pay as you go”?

You rent computing resources and are charged for what you consume, instead of buying hardware outright. Capacity can grow or shrink with demand.

UNIT 5 IN ONE BREATH

IoT senses and reports; blockchain records without letting anyone quietly rewrite history; the cloud rents out the computing; NLP and speech let machines handle human language; robots act in the physical world. The more power these systems have, the more the designer's ethics matter.

6.1 Technology addiction

Technology addiction is excessive, compulsive use of phones, computers, games or social media that damages daily life, relationships or wellbeing — like gambling, the compulsion matters more than the amount of time.

The test is not “how long?” but “does it hurt, and can you stop?”. The effects cluster into three groups: mental (anxiety, depression, comparison with others, isolation, less face-to-face contact); academic and work (constant distraction, lower grades, reduced productivity); and privacy (oversharing, higher exposure to scams).

ANALOGY

A notification is a vending machine for attention: one small pull, an instant reward, and soon you are reaching for it without deciding to. The fix is not willpower alone but removing the machine from the room.

6.4 Cloud: public and private

A public cloud is owned by a provider and shared by many customers over the internet. A private cloud is used by one organisation only, usually inside its own data centre, giving more control over data.

Securing either one comes down to five controls: encryption in transit and at rest; access control with least privilege and multi-factor authentication; monitoring and incident response; privacy policies and data minimisation; and network security with firewalls, segmentation and a VPC.

Hardware locks the door; software watches the window. Neither is enough alone — the textbook always wants “both”.

6.6 Cybersecurity

Cybersecurity is the practice of protecting systems, networks and data from unauthorised access and attack, preserving confidentiality, integrity and availability. It matters because our financial records, medical histories and identities now live online.

Cybercrime laws define the offences and the punishments, and tell police how to investigate. Common crimes include hacking, identity theft, phishing, malware, data breaches, cyberbullying, intellectual-property theft and cyberterrorism.

Where to report

Local police or a dedicated cybercrime unit; government cybersecurity agencies with hotlines and portals; your internet service provider, if the abuse runs through its network; banks or financial institutions for fraudulent transactions; and official online reporting portals, some of which allow anonymous reports.

6.7–6.8 Safety, security and cyberbullying

Safety on social media is a shared job — platforms, policymakers, teachers, parents and users. Three pressures dominate: privacy (adjust settings, share less), harassment (report, block, support the victim) and peer pressure (build the confidence to refuse).

Cyberbullying is using digital tools to hurt, threaten or humiliate — mean messages, rumours, leaked private information, in games or on social media. It follows you home, so its effects are persistent: anxiety, depression, low self-esteem, falling grades, social isolation, headaches and sleep loss.

  • Teach digital literacy and empathy.
  • Parents involved, with agreed rules.
  • Clear school and workplace anti-bullying policies.
  • Anonymous reporting that is acted on quickly.
  • Platforms that remove harmful content and ban repeat offenders.

6.10–6.11 The digital divide

The digital divide is the gap between those with reliable access to technology and the skills to use it, and those without. It has three layers:

LayerThe gap
Access divideno infrastructure (rural broadband), or unaffordable devices and data
Usage dividelow digital literacy; content not in your language or not relevant
Participation / global dividefewer online opportunities, services and jobs; richer vs poorer countries

The consequence is inequitable access to information: a student in a village with a weak connection cannot reach the same lessons, health advice or job listings as a student in the city. That is not a technology problem alone — it is an equality problem, and the remedies are cheaper data, shared devices, public access points and digital-literacy training.

QUICK CHECK

Is all heavy phone use addiction?

No. The defining feature is harm plus loss of control: the use damages sleep, study, work or relationships and the person cannot cut back.

Why is secure boot a hardware defence?

It is enforced by the firmware before the operating system loads, checking that only trusted, signed software starts — so malware cannot hijack the boot process.

Give one access divide and one usage divide example.

Access: a rural area with no broadband. Usage: a person with a connection but no digital skills, or no content in their own language.

UNIT 6 IN ONE BREATH

Computing gives access, speed and connection, and charges for them in attention, privacy and electricity. Protect the device with hardware and software, protect the person with boundaries and reporting, and remember that equal access is still not equal.
